# Report Directory Taxonomy

This directory contains two tracked report libraries and local generated outputs.

- `Chinese reports/`: Chinese experiment reports.
- `English reports/`: English experiment reports with the same taxonomy.
- Root-level `.json`, `.csv`, `.xlsx`, and threshold markdown outputs are generated by scripts and intentionally kept local through `.gitignore`.

Both language libraries use the following subdirectories:

| Directory | Scope |
|---|---|
| `00_summary_decisions/` | Project-level summaries, final validation notes, and model-freeze decisions. |
| `01_baseline_model_screening/` | Single-model baselines, training recipe checks, model-size comparisons, and architecture screening. |
| `02_roi_segmentation/` | ROI cropping, segmentation, LCC post-processing, area gates, and ROI-guided evaluation. |
| `03_ensemble_oof_stacking/` | OOF protocols, model ensembling, stacking, weight search, and ensemble member selection. |
| `04_tta_threshold_external_eval/` | Test-time augmentation, threshold analysis, and external evaluation sweeps. |
| `05_error_metrics_visuals/` | Error analysis, competition metric audits, visual evidence, and reporting tables. |
| `06_demo_release_defense/` | Demo rehearsal, packaging, release notes, formal command records, and defense material drafts. |

The categorized reports are the source-of-record narrative documents. Runtime artifacts in the root of `artifacts/reports/` are reproducibility caches or script outputs and should not be used as the primary documentation index.
