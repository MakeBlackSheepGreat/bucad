LesioNeXt-LEA Submission Delivery
Prepared: 2026-08-21

This delivery folder contains the complete, minimal set of files needed for
the IEEE Sensors Letters Author Portal. Do not upload this outer delivery ZIP
as a single manuscript file. Upload the indicated files to their matching
portal fields.

1. Main Manuscript
   Upload 03_Portal_Upload_Files/01_Main_Manuscript_LaTeX_Source.zip to
   "Main Manuscript". It contains the complete compilable Letter source:
   lesionext_lea_lsens.tex, IEEE_lsens.cls, and both PDF figures.

2. Graphical Abstract Image
   Upload 03_Portal_Upload_Files/02_Graphical_Abstract.png.

3. Cover Letter
   Upload 03_Portal_Upload_Files/03_Cover_Letter.pdf to
   "Sensors Letters - Cover Letter".

4. Supplementary Material
   Upload 03_Portal_Upload_Files/04_Supplementary_Material.pdf to
   "Supplementary Material for Review".

For local inspection and recovery, the manuscript source is also expanded in
01_Main_Manuscript_LaTeX_Source, and the supplementary source and compiled PDF
are in 02_Supplementary_LaTeX_Source. The compiled manuscript PDF is included
in 03_Portal_Upload_Files only as a local proof and is not a separate required
upload when the portal accepts the LaTeX source ZIP.

The main manuscript source compiles to a three-page PDF using IEEE_lsens.cls.
The package has been checked for complete citation-key coverage and contains
no auxiliary build artifacts.
